### ⚡ [Orchify](https://github.com/Abhijit-Deshmane/orchify) — Cloud-Native Visual Workflow Automation Platform
> Next.js 15 · React 19 · TypeScript · PostgreSQL · Prisma · React Flow · Inngest · tRPC v11

- **DAG Execution Engine:** Engineered a directed acyclic graph engine using **topological sorting & cycle detection** to ensure deterministic execution sequences for complex multi-node workflows.
- **Zero-Loss Durable Execution:** Orchestrated background workflows via **Inngest durable step functions** with automated retries, state persistence, and webhooks (Stripe, Google Forms, Slack, Discord).
- **Real-Time Observability:** Streamed live node telemetry (`loading`, `success`, `error`) directly to the React Flow canvas via **Server-Sent Events (SSE)** using `@inngest/realtime`.
- **Zero-Trust Security:** Built an encrypted credential vault using symmetric **AES-256-GCM** encryption at rest to safeguard LLM provider keys (OpenAI, Gemini, Anthropic).

### 🌐 [Navix](https://github.com/Abhijit-Deshmane/Navix) — Collaborative AI Browser Automation & Web Agent Platform

- **Autonomous Browser Agents:** Leveraged Stagehand and Browserbase sandboxes to replace brittle CSS selectors with natural language semantic web actions (Observe, Extract, Act) powered by Gemini Flash.
- **Multiplayer Visual Canvas:** Implemented real-time collaborative graph editing with multi-cursor presence and conflict-free state sync powered by **Liveblocks CRDTs** and React Flow.
- **Durable Background Pipelines:** Orchestrated asynchronous execution jobs via **Trigger.dev v4**, resolving dynamic variable interpolation (`{{ node.path }}`) across graph steps.
- **Visual Session Replay:** Captured full cloud browser execution telemetry, streaming `.m3u8` **HLS video recordings** directly to the UI via `hls.js` for instant visual debugging.
